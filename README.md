# Telkom University Company Profile - Praktikum
Project simulasi HTML, CSS, PHP native, MySQL/MariaDB, dan Git.

## Cara Menjalankan Project

1. Jalankan Apache dan MySQL melalui XAMPP.
2. Pastikan database `telkom_profile` sudah dibuat.
3. Simpan project di folder `C:\xampp\htdocs\telkom-company-profile`.
4. Buka browser dan akses `http://localhost/telkom-company-profile/`.
